Prototype note · 原型提示

TapTalk currently works best on Chrome for macOS

This prototype is currently fully supported on Google Chrome for macOS. Other browsers and Windows may not support local voices or recording yet.

TapTalk 原型目前仅在macOS 版 Google Chrome上获得完整支持。其他浏览器及 Windows 暂时可能不支持本地语音或录制功能。

Want to run TapTalk on your own Mac? Get the project on GitHub and follow the README. If you enjoy it, a star would mean a lot ♡

想在自己的 Mac 上部署 TapTalk？前往 GitHub 获取项目并按照 README 操作。如果你喜欢 TapTalk，欢迎点个 Star 支持一下 ♡
